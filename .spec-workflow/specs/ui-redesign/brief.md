# CoSphere 全站 UI / UX 重设计交付说明

> 目的: 为 Gemini / 设计团队提供**完整的信息架构、业务属性、数据字段和交互要求**, 覆盖当前所有菜单、页面与即将上线的订阅体系, 方便直接进入线框与视觉阶段。

## -1. 核心业务 & 用户 & 视觉定位
### 核心业务
- **AI 网关与计费运营平台**: 聚合多云/多模型渠道, 提供统一接入、智能路由、配额计时、钱包与订阅混合计费、监控告警等能力。
- **主要场景**:
  1. 企业/团队将自家应用接入多模型(如 GPT-4/Claude/Midjourney), 通过 CoSphere 统一发起请求并计费。
  2. 运营方以钱包充值+订阅套餐向下游客户出售配额, 支持兑换码、优惠券、第三方支付、余额/订阅优先扣费。
  3. 运维监控渠道余额/延迟、自动封禁异常、动态调整模型倍率。

### 用户人群
| 类别 | 代表角色 | 需求与行为 |
|------|----------|-----------|
| API / 产品团队 | 技术负责人、后端/数据工程师 | 快速配置令牌、调试接口、查看日志、控制成本、管理订阅与余额 |
| 渠道/运维 | 运维、SRE、渠道管理员 | 维护渠道可用性、调度策略、模型费用、监控告警、兑换码活动 |
| 财务/客服 | 财务专员、CSM | 充值、退款、账单导出、订阅订单处理、通知用户 |
| 管理层 | CTO/COO/创始人 | 查看 Dashboard、套餐 ROI、成本趋势、品牌一致性 |
| 超级管理员 | 平台所有者 | 初始化系统、配置全局开关、管理菜单/权限/品牌、多语言 |

### 推荐视觉/交互风格
- **品牌语调**: 专业、可信赖、具科技感。主色建议为深蓝/靛青(`(#111827 ~ #1f2937)`)，辅色采用霓虹蓝/青(`(#38bdf8)`)、紫(`(#7c3aed)`)强调创新; 状态色需与告警一致(绿/黄/红)。
- **布局**: B2B SaaS 规范——顶部导航+左侧菜单, 主要区域使用卡片/面板/表格, 支持深浅色模式。
- **组件风格**: 大量表格、Drawer、Tab、Step Form、拖拽列表、图表。强调可视化配置(矩阵/树状/进度条)。
- **文案与图标**: 以数据驱动文案(“请求成功率 99.95%”), 图标线性/等距, 突出状态。
- **动效**: 轻量 hover/进度动效, 拖拽排序有即时反馈; 告警和关键提示用条形 Banner。

## 2. 菜单逐项说明
本节按菜单粒度详细描述数据结构、交互流程、业务属性与优化建议。

### 2.1 公共站点
#### 2.1.1 Home (`/`)
- **内容模块**: Hero(标题、副标题、CTA)、问题痛点、功能模块(渠道聚合/多模型/监控)、案例或合作伙伴、CTA(注册/联系销售)、FAQ。
- **数据属性**: 多语言文案(i18n key)、背景图/视频、CTA 链接(注册/登录/联系邮件)、统计数字(支持模型数量/QPS/可用地区)。
- **交互**: 语言切换、滚动锚点、动画展示、跳转至 Pricing/Docs。
- **优化**:
  1. 设计统一的“Section 组件库”, 支持后台组合配置(标题+描述+媒体+按钮)。
  2. 引入“实时状态条”: 显示系统可用性、支持模型更新。

#### 2.1.2 Pricing (`/pricing`)
- **结构**: 价格切换器(月/年/自定义)、按量 vs 订阅表格、功能比较、FAQ。
- **字段**: 套餐名称/价格/USD 换算/可用模型/额度、折扣标签、CTA 目标(注册/订阅/联系销售)。
- **优化**: 允许用户筛选模型类型(文本/图像/音频)、显示“包含订阅权益 vs 余额扣费”的视觉差异; 旁边加入“购买流程”引导。

#### 2.1.3 法务页面 (`/user-agreement`, `/privacy-policy`)
- **需求**: 长文本 + 目录, 支持搜索/锚点; 需显示最后更新日期。
- **优化**: sticky 目录, 提供下载 PDF。

### 2.2 体验入口
#### 2.2.1 Playground (`/playground`)
- **核心功能**: 选择模型/渠道、输入 prompt、设置参数(温度/Top-P/输出 tokens)、查看响应/日志。
- **数据属性**:
  - 模型列表(模型名称、分组、倍率/价格、是否订阅可用)。
  - 参数默认值、请求头/路径、历史请求记录。
  - 计费信息: 预计额度、实际扣费、扣费来源(订阅ID/余额)。
- **交互**: 左侧模型面板、中央编辑器、输出区域；支持保存预设、复制 cURL；显示调用耗时/响应大小。
- **优化**: 1) 引入“预设库”(行业模板); 2) 在结果区展示“使用的订阅/余额”与剩余限额; 3) 支持多 tab 并行调试。

#### 2.2.2 Chat (`/chat`)/Chat2Link (`/chat2link`)
- **功能点**: 会话列表、消息输入、流式输出、上下文管理、分享链接生成、链接失效控制。
- **数据**: 会话 ID/标题/模型/状态、消息历史、分享链接有效期/密码、使用的额度。
- **优化**:
  - 聊天页面提供“模型/渠道”切换器、显示当前订阅状态。
  - Chat2Link 使用卡片列出所有分享链接(创建时间/访问次数/有效状态), 支持复制/失效操作。

#### 2.2.3 Midjourney 操作台 (`/midjourney`)
- **功能**: Submits MJ 任务, 控制参数, 预览结果, 查看耗时、状态。
- **数据**: 任务 ID、Prompt、分辨率、状态(queued/running/done/error)、耗费额度、生成图片 URL、渠道。
- **优化**: 用画廊+状态标签显示任务; 详情 Drawer 展示参数、再次生成、扣费详情；可视化渠道延迟/失败率。

### 2.3 控制台 Workspace
#### 2.3.1 数据看板 `/detail`
- **信息块**: 总调用次数/成功率/失败原因、分模型/分渠道调用、余额/订阅额度、活跃用户、渠道延迟、Top 错误。
- **数据源**: KPI (时间区间、比较值)、图表类型(折线/柱状/饼图)、告警阈值。
- **优化**:
  1. 顶部 Summary 卡片(今日 vs 昨日) + 筛选器(时间/用户/分组)。
  2. 中部图表区(请求量、订阅 vs 余额使用、渠道健康度)。
  3. 底部日志快照或“待处理事项”。

#### 2.3.2 令牌管理 `/token`
- **列表字段**: Token 名称/ID、状态(启用/禁用)、剩余额度(绝对值+百分比)、绑定用户、模型限制(多值)、分组优先、自动分组、订阅优先计费、创建时间。
- **详情/表单字段**:
  - 基础: 名称、标签、备注。
  - 配额: 初始额度、无限额度、失效时间。
  - 安全: IP 白名单、多因子？
  - 模型限制: JSON → 改为可视化选择 + 规则(允许/禁止列表)。
  - 分组/渠道: 自动分组(auto_smart_group)用于分组不可用时自动回退；订阅优先计费(subscription_preferred)控制是否进入订阅扣费；自定义分组=选择渠道组 + 优先级。
- **交互**: 列表批量启用/禁用、复制 Token、查看使用趋势；详情 Drawer 多步骤导航。
- **优化**: 1) 分组优先排序器(拖拽/权重)；2) 模型限制 Tag + 搜索；3) 显示当前订阅扣费状态(若 token 跳过订阅需告警)。

#### 2.3.3 使用日志 `/log`
- **字段**: 时间、请求ID、用户/令牌、模型、渠道、消耗额度、订阅ID/余额、耗时、状态码、错误描述、输入/输出 tokens。
- **操作**: 过滤(时间范围、用户、模型、渠道、错误)、导出 CSV、查看详情(上下游请求)、重放(可选)。
- **优化**: 统一筛选抽屉、保存视图、实时刷新模式; 详情弹窗展示调用栈(入口→渠道→上游)和计费信息。

#### 2.3.4 Midjourney & Task 日志 `/midjourney-log`, `/task`
- **数据**: 任务ID、类型(Imagine/Variation)、状态、图片结果、消耗、失败原因。
- **优化**: 状态列显眼, 行内操作(重试/终止), 详情 Drawer 展示图像+Prompt+扣费; Task 页面使用看板区分状态列。

### 2.4 财务与个人
#### 2.4.1 钱包管理 `/topup`
- **模块**:
  1. **余额概览**: 当前余额(USD/Quota)、订阅+余额使用趋势、自动扣费提示。
  2. **在线充值**: 选择金额/渠道、支付二维码、状态轮询。
  3. **兑换码充值**: 输入兑换码、校验、展示获得额度/订阅。
  4. **钱包记录**: 账单表(时间、类型、金额、渠道、关联订单/订阅)。
- **优化**:
  - 分 Tab 展示不同充值方式, 侧边固定“余额与订阅状态”。
  - 充值完成后显示“下一步(查看账单/配置订阅)”CTA。
  - 账单表支持标签过滤(充值/扣费/订阅/退款)。

#### 2.4.2 个人设置 `/personal`
- **子页面**:
  - 个人信息: 昵称、邮箱、角色、API Key。
  - 安全设置: 两步验证、密码、更换邮箱。
  - 通知偏好: 邮件/Slack/Webhook/短信, 事件类型(余额低、订阅将到期、渠道失败), 需展示示例文案。
  - 客户端下载/桌面统计: 版本信息。
- **交互优化**:
  - 使用 Tab + 卡片, 每项包含描述/状态/操作。
  - 通知偏好改为 GUI(多选/权重), 提供测试按钮。
  - 显示“订阅自动兜底开关”入口, 与订阅模块联动。

### 2.5 订阅模块(新增)
#### 2.5.1 Admin 端
1. **套餐管理 `/subscription/plan`**
   - 字段: 名称/多语言描述、SKU、封面、状态、价格(支持多币种)、计费周期(月/年/自定义天数)、允许渠道分组/模型、自动兜底默认值。
   - 限额配置: Period=5h/Day/Week/Month, Quota, 单位(quota→展示USD)，启用/禁用, 滚动窗口策略。
   - 其他: 开售/下架时间, 排序权重, 标签(推荐/热门)。
   - 交互建议: 卡片列表 + Drawer; 限额以表格呈现, 支持批量编辑/复制; “预览用户视图”按钮。

2. **优惠券 `/subscription/coupon`**
   - 字段: 名称、类型(折扣/立减)、折扣值、适用套餐(多选)、生效/过期时间、发行量、每用户限用次数、绑定用户/兑换码、状态(active/reserved/used/expired)。
   - 交互: 列表+过滤, 详情展示使用记录, 操作(复制、停用、绑定兑换码)。
   - 建议: 创建流程采用多步骤表单(基础→范围→数量→预览), 显示示例金额。

3. **兑换码 `/subscription/redemption`**
   - 字段: 批次名称、生成数量、类型(额度/订阅)、绑定套餐/优惠券/用户、有效期、导出文件。
   - 交互: 批量生成 -> 下载文本/CSV, 显示已使用/未使用统计; 支持重新绑定优惠券(兑换前)。
   - 建议: 与原余额兑换码共享界面, Tab 区分业务, 在详情中展示关联订阅。

4. **订阅订单 `/subscription/orders`**
   - 字段: 订单ID、用户、套餐、支付方式(余额/第三方/兑换/赠送)、原价、折扣、实付、状态、关联账单ID、创建时间。
   - 交互: 表格 + 筛选；详情 Drawer 展示 plan snapshot、coupon snapshot、支付流水；操作(取消订单、标记人工退款)。

5. **订阅使用监控 `/subscription/usage`**
   - 数据: 用户/订阅ID、周期(five_hours/day/week/month)窗口起止、限额/已用/剩余、刷新倒计时、最近一次扣费来源。
   - 交互: 支持过滤(用户/计划/周期), 详情显示使用曲线; 提供“重置窗口/刷新缓存”操作。

#### 2.5.2 用户端
1. **订阅中心 `/subscription/store`**
   - 内容: 可购买套餐列表, 每个卡片显示价格/周期/每周期限额/支持模型/渠道/自动兜底提示。
   - 交互: 筛选(周期、价格区间、模型)、排序(推荐/价格/热度), 点击进入详情(含图表/FAQ/对比表)。

2. **结算流程 `/subscription/checkout`**
   - 流程: 选择套餐 → 选择支付方式(余额/第三方/兑换码) → 单张优惠券选择器 → 自动兜底开关 → 确认条款 → 支付。
   - UI: 采用两列布局(左侧表单, 右侧价格摘要), 显示预计开始/结束时间、各周期限额摘要。

3. **我的订阅 `/subscription/me`**
   - 显示: 当前订阅(s) 卡片, 包含状态/剩余天数/到期倒计时；每个周期的使用进度条(显示滚动窗口起止/剩余)；支持模型列表；订阅优先级列表(拖拽); 自动兜底开关, 说明其影响；历史记录(订阅/续费/取消/折算, 可导出)。
   - 操作: 调整优先级、续订、兑换、查看扣费明细、开启/关闭自动兜底。
   - 状态提示: 若某订阅因令牌订阅优先关闭被跳过, 显示警示 banner 并提供跳转。

4. **兑换流程 `/subscription/redeem`**
   - 输入兑换码 → 校验 → 若与当前订阅冲突, 弹出对比窗:
     - 并存: 列出两个套餐差异, 允许调整优先级。
     - 折算: 显示旧套餐剩余天数、折算金额、向下取整后的追加天数、剩余金额备注。
   - 成功后显示新订阅卡片 + 引导下一步(调整优先级/开启兜底)。

### 2.6 管理后台
#### 2.6.1 渠道管理 `/channel`
- **列表字段**: 名称、渠道类型(OpenAI/Azure/...)/模式(单/多key)、分组、模型覆盖、余额、速率限制、状态(启用/禁用/自动封禁)、延迟/成功率、最近更新。
- **详情**: 基础信息、密钥配置、模型映射(支持/权重)、负载策略、监控日志、告警阈值、自动恢复策略。
- **操作**: 更新余额(单个/批量)、测试连通性、启用自动封禁、配置费率。
- **优化**: 采用分栏布局 + Tab, 让“模型映射”使用树状/表格, 支持 JSON 导入/导出但主流程 GUI。

#### 2.6.2 模型管理 `/models`
- **功能**: 配置模型列表、倍率、别名、渠道映射、用户可见性。
- **数据**: 模型名称/类型/默认倍率、渠道优先级、可用组、成本。
- **优化**: 建立“分组 → 模型 → 渠道”可视化矩阵, 提供拖拽调整、批量编辑；“分组与定价 JSON”改成 GUI, 提供版本管理、自动校验。

#### 2.6.3 兑换码管理 `/redemption`
- 现有额度兑换码, 需与订阅兑换码共享框架。
- **字段**: 批次/类型/额度、数量、已用/未用、导出、关联用户。
- **建议**: Tab “余额兑换码/订阅兑换码”, 统一创建流程, 行内显示绑定优惠券/订阅。

#### 2.6.4 用户管理 `/user`
- **内容**: 用户列表(账号、角色、余额、订阅数量、状态、最后登录)、详情(额度、订阅、API key、通知偏好)、操作(启用/禁用/加减额度/重置密码/发邮件)。
- **优化**: 右侧详情 Drawer + 关键指标卡片; 提供批量操作和标签筛选(企业/个人/VIP)。

#### 2.6.5 系统设置 `/setting`
- **分组**(可在左侧导航/Tab 显示):
  1. 基础信息: 品牌、Logo、主题色、域名、语言设置。
  2. 登录注册: OAuth 配置、验证码策略、邀请制、登录背景。
  3. 邮件/短信/通知网关。
  4. 菜单与权限: 参考 `SettingsSidebarModulesAdmin`, 可视化树(区域→模块→开关), 提供预览。
  5. 渠道/模型参数: **原 JSON** (“分组与模型定价”) → GUI 矩阵, 支持批量编辑、CSV 导入、版本回滚。
  6. 订阅配置: 默认自动兜底、通知阈值、折算策略说明、Feature Flag。
  7. 日志/审计: 目标存储、保留时长。
- **优化**: 统一 Search、分区折叠、危险操作需要确认/备份导出。

#### 2.6.6 Setup `/setup`
- **步骤**: 1) 检查依赖 → 2) 创建超级管理员 → 3) 渠道示例 → 4) 品牌设置 → 5) 完成。
- **需求**: 每步显示说明 & 校验; 提供导入示例数据按钮; 背景图/插画统一。

## 4. 跨页面交互规范 (必须在设计中体现)
1. **订阅 vs 钱包优先级**: 在 Playground、Chat、Token 列表、Usage Log、钱包、订阅页面都需显示“当前订阅扣费状态/自动兜底开关/提示被令牌订阅优先关闭跳过”。
2. **滚动窗口提示**: 订阅卡片应展示每个周期的窗口起止时间、剩余额度、刷新倒计时; 当窗口即将刷新时给出提醒。
3. **拖拽排序**: 应用于订阅优先级、令牌分组优先级、模型/渠道列表; 需提供拖拽手柄、序号、保存提示。
4. **JSON→GUI**: 渠道组/模型倍率/通知模板等所有 JSON 配置应有 GUI 界面, 同时提供“查看原 JSON / 导出”按钮。
5. **多语言**: 文案较长时需自动换行; 设计时需标注各组件最长文字长度。
6. **状态反馈**: 所有危险操作(取消订阅、禁用渠道、批量导出)需要对话框 + 二次确认; 成功操作统一使用 Toast + 描述下一步。
7. **表格操作**: 表格顶部固定工具栏(筛选、导出、批量操作); 行点击进入详情 Drawer。
8. **通知/告警**: 全局 Header 需可显示红点提示(即将到期的订阅/余额不足/渠道告警), 点击跳转对应页面。
9. **导出/下载**: 兑换码、账单、日志等需要统一的“导出面板”(选择字段/格式/时间范围)。
10. **移动端兼容**: 至少保证公共站点和购买流程在移动端可用(响应式断点 375px/768px/1200px)。

## 5. 待优化功能清单 (供设计重点关注)
1. **系统设置 → 分组与模型定价**: 以 GUI 矩阵替代 JSON，支持版本管理/回滚/校验。
2. **令牌创建**: 引入向导+模板(默认/只读/高安全)，减少一次性长表单。
3. **Usage Log**: 保存视图、实时刷新、展示请求链路、导出入口固定。
4. **Playground**: 升级为多面板布局，涵盖请求参数、历史、计费提示、订阅使用情况。
5. **钱包充值**: 区分充值方式，提供成功后的下一步指引；兑换码输入支持粘贴自动校验。
6. **订阅优先级**: 卡片式列表 + 拖拽, 显示剩余天数/各周期用量; 提供批量排序策略选项(到期时间/价格/剩余额度)。
7. **优惠券/兑换码创建**: wizard, 显示预览, 支持导出 Excel 并包含二维码/链接。
8. **通知设置**: 卡片化, 提供示例内容 & 测试按钮, 可定义阈值(余额<value, 订阅剩余天数 < value)。
9. **渠道详情**: Tab 切换, 结合图表显示延迟/失败率, 支持一键更新余额。
10. **订阅使用监控**: 用图表展示滚动窗口, 并允许管理员强制刷新窗口/同步缓存。

## 7. 页面功能清单 (逐页详细)
> 按路由逐项列出核心数据、交互、必要的空态/错误态与可优化点, 便于设计直接落地。

### 7.1 公共站点
- **Home `/`**: Hero(标题/副标题/CTA)、能力亮点、解决方案卡片、客户案例、FAQ、页脚(社交/支持)。空态: 当服务状态异常可显示状态条。优化: Section 组件化+动画滚动锚点。
- **Pricing `/pricing`**: 价格切换(月/年/自定义)、按量 vs 订阅表格(字段: 名称/价格/额度/模型/渠道/周期)、FAQ、CTA。支持货币/语言切换。优化: 对比视图 + 套餐推荐标签。
- **About `/about`**: 公司介绍、版本信息、支持链接。可加“更新日志”卡片。
- **UserAgreement / PrivacyPolicy**: 长文 + 目录 + 搜索/锚点; 空态: 加载失败提示。优化: PDF 下载。
- **Forbidden / NotFound**: 状态插画 + CTA(返回首页/登录)。

### 7.2 体验入口
- **Playground `/playground`**: 左侧模型&渠道选择(字段: 模型/分组/倍率/订阅可用)、参数表单(温度/TopP/MaxTokens/流式/系统提示)、请求/响应面板、历史记录、复制 cURL、计费提示(预计/实际、来源订阅/余额)。空态: 首次使用引导。优化: 预设模板库、并行 Tabs、可视化延迟与费用。
- **Chat `/chat`**: 会话列表、消息窗口、模型/渠道切换、重置上下文、流式输出、文件上传(如有)、使用订阅状态提示。空态: “新建会话”引导。优化: 历史消息搜索、快捷插入预设。
- **Chat2Link `/chat2link`**: 生成分享链接(字段: 有效期/密码/访问次数/绑定模型)、链接列表(状态/复制/失效/统计)。空态: 引导创建。
- **Midjourney `/midjourney`**: 提交绘图任务表单(参数: prompt/尺寸/风格), 任务列表(状态/耗时/额度/预览), 操作(重试/变体/放大)。优化: 画廊+时间线视图, 状态筛选。

### 7.3 控制台 Workspace
- **Dashboard `/detail`**: KPI 卡(请求数/成功率/成本/渠道延迟/订阅使用)，时间筛选，图表(折线/柱状/饼)，Top 错误列表，告警条。优化: 自定义卡片布局与保存视图。
- **Token `/token`**: 列表字段: 名称/状态/剩余额度/分组/模型限制/订阅优先(bool)/创建时间。操作: 创建/编辑 Drawer(基础、配额、安全、模型限制、分组优先/订阅优先)、批量启用/禁用、复制 Key、重置额度。优化: 分步表单、分组拖拽排序器、模型多选+搜索。
- **Usage Log `/log`**: 表格字段: 时间、请求ID、用户/令牌、模型、渠道、消耗额度、来源(订阅/余额)、耗时、状态码/错误、输入输出 tokens(可折叠)。筛选: 时间范围、用户、模型、渠道、错误码、来源。操作: 导出、保存视图、实时刷新。详情 Drawer: 请求链路 & 计费信息。
- **Midjourney Log `/midjourney-log`**: 任务ID、状态、图片预览、耗费、模型/渠道、失败原因; 状态筛选、批量重试/终止。
- **Task `/task`**: 任务列表(类型/状态/创建时间/耗时/执行节点)、操作(重试/取消)。优化: 看板视图区分状态。

### 7.4 财务与个人
- **TopUp `/topup`**: 余额概览(余额/订阅状态)、充值 Tab(在线/兑换码/转移)、支付二维码/状态轮询、充值记录(时间/类型/金额/渠道/订单ID)、导出。空态: 未充值提示。优化: 成功后 CTA 进入账单/订阅。
- **Personal `/personal`**: 子页签：个人信息、API Key/令牌、通知偏好(邮件/Slack/Webhook/SMS + 事件)、安全设置(2FA/密码)、客户端。操作: 生成/吊销 API Key、测试通知。优化: 卡片+描述+测试按钮。

### 7.5 订阅模块 (新设计)
- **Admin /subscription/plan**: 表格字段: 名称/价格/周期/状态/生效时间/渠道分组/模型/自动兜底默认。详情/表单: 基础信息、封面、限额表(5h/日/周/月 quota+启用+单位+窗口策略)、模型/渠道多选、标签、排序权重、预览用户视图。操作: 上下架、复制、导出。
- **Admin /subscription/coupon**: 列表: 名称/类型/折扣/适用套餐/数量/已用/有效期/状态/绑定用户或兑换码。操作: 创建向导(基础→范围→数量→预览)、绑定/解绑兑换码(兑换前)、停用、导出。
- **Admin /subscription/redemption**: 列表: 批次/类型(额度/订阅)/数量/已用/绑定套餐/绑定优惠券/有效期/导出。创建: 步骤式(基础→绑定套餐→绑定优惠券→完成)。
- **Admin /subscription/orders**: 表格: 订单ID/用户/套餐/支付方式/原价/折扣/实付/状态/账单ID/创建时间。操作: 筛选、查看快照、取消、标记人工退款。
- **Admin /subscription/usage**: 列表: 用户/订阅ID/周期/窗口起止/限额/已用/剩余/刷新倒计时。操作: 刷新窗口、同步缓存、导出。
- **User /subscription/store**: 卡片/对比表展示套餐(价格/周期/限额/模型/渠道/标签), 筛选/排序, CTA 购买。
- **User /subscription/checkout**: 侧边价格摘要, 支付方式(余额/第三方/兑换码), 单张优惠券选择器, 自动兜底开关, 起止时间/限额摘要, 条款勾选。
- **User /subscription/me**: 多订阅卡片(状态/到期/倒计时)、周期进度条(窗口起止/剩余/刷新倒计时)、优先级拖拽列表、自动兜底开关、历史记录(续费/折算/取消/兑换)、提示订阅被令牌订阅优先关闭跳过时的 Banner。
- **User /subscription/redeem**: 输入兑换码→校验→冲突处理弹窗(并存 vs 折算向下取整)、展示折算金额/追加天数、成功卡片与下一步指引(调整优先级/开启兜底)。

### 7.6 管理后台
- **Channel `/channel`**: 表格字段: 名称/类型/模式/分组/余额/状态/成功率/延迟/自动封禁/模型覆盖/最近更新。操作: 新增/编辑(基础/密钥/模型映射/负载策略/告警), 批量更新余额, 测试连通性, 自动封禁开关。详情 Tab: 基础/模型映射/监控/日志。
- **Models `/models`**: 模型列表(名称/类型/倍率/默认渠道/可见性/标签)、分组与定价矩阵(替代 JSON)。操作: 新增模型、编辑倍率、拖拽渠道优先级、导入导出配置。
- **Redemption `/redemption`**: 额度兑换码(现有) + 订阅兑换码 Tab; 字段: 批次/类型/额度或套餐/数量/已用/绑定优惠券/用户/有效期/导出。操作: 生成、停用、删除无效、导出。
- **User `/user`**: 列表: 邮箱/角色/余额/订阅数/状态/最后登录; 操作: 启用/禁用、加减额度、重置密码、发邮件、查看详情 Drawer(额度、订阅、API Key、通知偏好)。
- **Setting `/setting`**: 分组: 基础信息、登录注册(OAuth/验证码/邀请)、通知网关(邮件/短信/Slack/Webhook)、菜单权限(树+开关, 参考 SettingsSidebarModulesAdmin)、渠道与模型参数(矩阵 GUI, 支持 JSON 导出)、订阅配置(自动兜底默认、阈值、Feature Flag)、日志/审计、品牌主题。操作: 保存/发布/导出备份/版本回滚。
- **Setup `/setup`**: 向导步骤: 环境检测→创建超级管理员→渠道示例→品牌设置→完成; 显示校验结果与“导入示例配置”。

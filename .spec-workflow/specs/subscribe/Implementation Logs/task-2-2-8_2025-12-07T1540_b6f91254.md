### 修正的核心逻辑

#### 原错误理解
- 滚动窗口从订阅开始时间计算
- 窗口结束后立即开始下一个窗口

#### 正确逻辑（按需触发滚动窗口）
- 窗口开始时间 = 用户**实际首次使用**服务的时间
- 窗口结束时间 = 窗口开始 + 周期时长
- 窗口结束后**不自动开始**下一窗口
- 下一窗口开始 = 用户在上个窗口过期后**再次使用**时触发

### 窗口策略对比

| 策略 | 窗口开始 | 窗口结束 | 下一窗口触发 |
|------|----------|----------|--------------|
| `rolling` | 首次使用时间 | 开始+周期 | 用户再次使用 |
| `fixed` | 自然边界(UTC 00:00) | 自然边界 | 自动对齐 |

### 关键实现代码

#### 按需触发滚动窗口核心逻辑
```go
func GetOrCreateActiveUsageWindow(subscriptionId int64, period string, limitQuota int64, strategy string) (*SubscriptionUsage, error) {
    now := common.GetTimestamp()

    // 1. 尝试获取活跃窗口（window_end >= now）
    usage, err := GetActiveUsageWindow(subscriptionId, period)
    if err != nil {
        return nil, err
    }
    if usage != nil {
        return usage, nil  // 存在活跃窗口，直接返回
    }

    // 2. 无活跃窗口，根据策略创建新窗口
    var windowStart, windowEnd int64
    if strategy == common.WindowStrategyRolling {
        // 滚动窗口：window_start = NOW（首次使用触发）
        windowStart = now
        windowEnd = CalculateRollingWindowEnd(period, windowStart)
    } else {
        // 固定窗口：使用自然边界
        windowStart, windowEnd = CalculateFixedWindowBounds(period, now)
    }

    // 3. 创建新窗口（UPSERT 保证并发安全）
    newUsage := SubscriptionUsage{
        SubscriptionId: subscriptionId,
        Period:         period,
        WindowStart:    windowStart,
        WindowEnd:      windowEnd,
        UsedQuota:      0,
        LimitQuota:     limitQuota,
    }
    // ... upsert logic
}
```

#### 滚动窗口结束时间计算
```go
func CalculateRollingWindowEnd(period string, windowStart int64) int64 {
    duration := GetWindowDurationSeconds(period)
    return windowStart + duration - 1
}
```

#### 活跃窗口查询（关键：window_end >= now）
```go
func GetActiveUsageWindow(subscriptionId int64, period string) (*SubscriptionUsage, error) {
    now := common.GetTimestamp()
    var usage SubscriptionUsage
    err := DB.Where("subscription_id = ? AND period = ? AND window_end >= ?",
        subscriptionId, period, now).
        Order("window_start DESC").
        First(&usage).Error
    if errors.Is(err, gorm.ErrRecordNotFound) {
        return nil, nil  // 无活跃窗口
    }
    return &usage, err
}
```

### 使用示例

```go
// 场景：用户订阅后首次使用（假设 15:00 使用，周期为 day）
// 滚动窗口：窗口开始 = 15:00，窗口结束 = 次日 14:59:59
// 固定窗口：窗口开始 = 当日 00:00 UTC，窗口结束 = 当日 23:59:59 UTC

usage, err := GetOrCreateActiveUsageWindow(
    subscriptionId,
    common.LimitPeriodDay,
    1000,  // 日限额 1000
    common.WindowStrategyRolling,  // 滚动策略
)

// 24小时后用户再次使用，旧窗口已过期
// 系统创建新窗口：开始 = 当前时间，结束 = 当前时间 + 24h - 1s
```
